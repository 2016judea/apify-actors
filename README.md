## How it is built

- `actors/<name>/spec.json`: title, description, categories, input schema, price, competitor prices. `impl.py`: `async def run(inp, client, emit)`. ArcGIS actors are generated from `config.json` by `scripts/new.py`.
- `common/main.py` and `common/lib.py` are copied into every actor at deploy time (retrying HTTP client, ArcGIS paging past maxRecordCount, Socrata paging).
- Billing uses the platform's `apify-default-dataset-item` event: one pushed row is one charge, and the run stops at the user's max-charge budget.

## Commands

```bash
.venv/bin/python scripts/local.py <name> '{"maxItems":3}' --save   # run locally, no Apify compute; saves sample.json
.venv/bin/python scripts/price.py "building permits"               # top-3 comparable Store actors and their per-result price
scripts/deploy_many.sh <name> [...]                                 # README, create/update, build, test run, price, try publish
scripts/publish_all.sh                                              # flip every priced actor public (after Store terms are accepted)
```

`ledger.tsv` is the record: actor, source, price, competitor prices, test-run rows, Store URL, status.

## Status

Publishing returns `403 store-terms-not-accepted` until the account owner accepts the Apify Store terms once in the Console. Then `scripts/publish_all.sh` lists everything.
